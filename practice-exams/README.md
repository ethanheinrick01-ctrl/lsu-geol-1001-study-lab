# Practice exams

Keep each exam self-contained:

```text
practice-exams/
└── exam-01/
    ├── README.md
    ├── questions.pdf
    ├── answer-key.md
    └── validation.md
```

`validation.md` should record:

- coverage by chapter and lecture;
- source evidence for each answer;
- independent answer-key check;
- difficulty and timing notes;
- confirmed gaps or uncertain items.

Do not upload a live graded exam or copied Connect question bank.
